# Isekai in the Real World – privacy policy

The privacy policy of the Isekai iPhone app (German and English), served with GitHub Pages:

**https://chrisay-22.github.io/isekai-privacy/**

This URL goes into App Store Connect. To change the policy, edit `index.html` and update the date at the top of
both language sections; GitHub Pages publishes the new version about a minute after the push.
